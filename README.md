# netlleuger

Portfolio of Petro Poliakov — founder of netlleuger. Web developer specializing in lightweight, fast, and accessible websites.

## Stack
- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages

## Files
- `index.html` — main single-page portfolio
- `favicon.svg` — square browser favicon based on the netlleuger mark
- `netlleuger-logo-transparent.svg` — transparent brand mark used in the hero
- `og-image.svg` — editable Open Graph source artwork
- `og-image.png` — 1200×630 social preview image referenced by Open Graph/Twitter metadata
- `robots.txt` — crawler policy and sitemap location
- `sitemap.xml` — XML sitemap for the home page
